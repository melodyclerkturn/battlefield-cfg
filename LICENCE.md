## 🧩 About

**Battlefield Cfg** is a comprehensive overlay menu for Battlefield 2042 featuring recoil control, aim assist tuning, HUD info, config profiles, and script macros.

Based on popular configs, community overlays, and custom script packs.

---

## ✨ Features

### 🎮 Core Tools
- Overlay Menu — toggle in-game panel with hotkey
- Recoil Control — reduce weapon kick while firing
- Aim Assist Tuning — adjust aim smoothing and FOV
- HUD Info — show target and player stats on screen
- Config Profiles — load and save per-weapon setups

### 🎨 Interface & Display
- Clean Overlay — lightweight panel with status readouts
- Custom Themes — switch color schemes and layouts
- Keybind Editor — rebind all hotkeys in menu

### 🏋️ Training & Setup
- Script Macros — automate weapon and movement sequences
- Loadout Presets — save class and weapon configurations
- Instant Apply — push new settings without restart
- Hotkey Profiles — switch configs mid-match
